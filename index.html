Портативний агент для коду з українським інтерфейсом

Cartel Code — це десктопний застосунок, який пише, читає й править код разом з вами. Власний шлюз API з пулом ключів, 168 плагінів, повністю українська оболонка. Node і Electron уже всередині: розпакували — працює.

Що всередині

П'ять речей, заради яких це збирали

Не перелік модних слів, а те, що справді відрізняє цю збірку від голого фреймворку.

  • Шлюз API з пулом ключів

    Кілька ключів на одного провайдера, ротація по колу між живими. Вичерпав квоту — ключ автоматично заморожується на заданий час, а запит тут же перемикається на наступний живий. Нічого не треба міняти вручну посеред роботи.

  • 168 плагінів

    Перевірений каталог розширень: «очі» для агента й робота із зображеннями, дашборд контексту з підрахунком токенів, машина часу по кроках діалогу. Встановлення — однією командою, без збирання з джерел.

  • Український інтерфейс

    Не машинний переклад поверх англійського: перекладено меню, підказки, стани й повідомлення про помилки — те, що читаєш щодня. Англійська лишається перемикачем на випадок звички.

  • Доступ через Telegram

    Вхід підтверджується акаунтом Telegram: пароль ми не бачимо, лише підтвердження від самого Telegram. Доступ відкритий учасникам обох спільнот YT Cartel.

  • Повна портативність

    Node і Electron лежать усередині папки. Нічого не пишеться в систему й реєстр, дані живуть поруч у теці data. Папку можна перенести на іншу машину разом з історією, ключами й плагінами.

Як запустити

Три кроки від завантаження до роботи

Встановлювати нічого не треба — ні Node.js, ні Python, ні Git.

  1. Завантажте збірку для своєї системи

    Для Windows — файл .exe, для macOS — .dmg. Кнопки вгорі вже підсвітили потрібну; якщо ви на іншому пристрої, беріть другий рядок.

  2. Розпакуйте та відкрийте

    Windows: запустіть завантажений файл і оберіть будь-яку папку, бажано зі шляхом без кирилиці й пробілів.

    macOS: відкрийте образ і перетягніть Cartel Code у «Програми». Перший запуск — правою кнопкою → «Відкрити», бо збірка ще не підписана Apple.

  3. Увійдіть і оберіть робочу папку

    При першому старті застосунок попросить підтвердити доступ через Telegram. Далі вкажіть теку проєкту, з якою працюватиме агент, і можна писати перший запит.

Питання

Коротко про головне

Чи потрібен встановлений Node.js або щось іще?

Ні. Портативні Node.js і Electron лежать усередині збірки й використовуються тільки нею. Системні версії не чіпаються, PATH не змінюється.

Де зберігаються мої дані та ключі?

Локально, у теці data поруч із застосунком: профілі, історія сесій, API-ключі, встановлені плагіни. Ця тека переноситься разом із папкою застосунку.

Запити до моделей ідуть напряму до вибраного вами провайдера через локальний шлюз на 127.0.0.1. Проміжних серверів немає.

macOS каже, що застосунок від невідомого розробника

Збірка поки не підписана сертифікатом Apple. Відкрийте її через праву кнопку → «Відкрити» й підтвердіть дію. Якщо система все одно блокує — «Системні параметри» → «Конфіденційність і безпека» → «Усе одно відкрити».

Що потрібно для доступу?

Членство в обох спільнотах YT Cartel. При першому запуску застосунок відкриє сторінку входу Telegram. Після підтвердження доступ лишається на пристрої.

Як оновлюється застосунок?

Cartel Code сам перевіряє нові релізи на GitHub і пропонує оновлення. Файл завантажується лише з github.com, а перед запуском звіряються розмір і контрольна сума SHA-256 — інакше оновлення не встановиться.
