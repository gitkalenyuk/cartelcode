# Cartel Code

Портативний десктопний агент для коду з українським інтерфейсом.
Власний шлюз API з пулом ключів, 168 плагінів, Windows і macOS.
Node і Electron уже всередині збірки — встановлювати нічого не треба.

### Завантажити

**→ [gitkalenyuk.github.io/cartelcode](https://gitkalenyuk.github.io/cartelcode)**

Сторінка сама визначить вашу систему й запропонує потрібний файл.
Прямі посилання на всі файли — у [релізах](https://github.com/gitkalenyuk/cartelcode/releases/latest):
`.exe` для Windows, `.dmg` для macOS (Apple Silicon та Intel).

### Доступ

Застосунок доступний учасникам обох спільнот YT Cartel.
Вхід підтверджується через Telegram при першому запуску.

### Що це за репозиторій

Тут лежать лише сторінка завантаження та самі релізи.
Вихідний код застосунку закритий і зберігається окремо.
